# Roblox OG — Edição PT-BR

Edição brasileira mantida por **Guilherme Gv** (@guilhermedigv).

O projeto personaliza a identidade de uma extensão comunitária de aprimoramento do site Roblox e adiciona uma camada de tradução para português do Brasil. **Não é um produto oficial da Roblox Corporation** e não possui afiliação, patrocínio ou endosso da empresa.

## Estado do repositório

Este repositório contém a apresentação inicial do projeto. O kit de compilação e os pacotes binários ainda precisam ser enviados como arquivos do repositório ou como ativos de uma release.

O kit preparado nesta conversa é um **kit de compilação**, não a extensão final instalável. O pacote instalável para Chrome e Edge só pode ser gerado depois de executar `build.bat` no Windows com Node.js 26.8.2 ou superior. O arquivo gerado será `Roblox-OG-4.5.1-Chrome-Edge.zip`.

## Compilação

Quando o kit for adicionado a este repositório:

1. Baixe e extraia o kit ZIP.
2. Instale Node.js 26.8.2 ou superior.
3. Execute `build.bat`.
4. Aguarde a compilação e os testes automatizados.
5. O ZIP instalável será salvo na pasta de saída indicada pelo script, se a compilação terminar sem erros.

## Status

A compilação final ainda precisa ser executada e validada em Windows/Node 26.8.2. Nenhuma publicação na Chrome Web Store ou Microsoft Edge Add-ons é afirmada por este repositório.
