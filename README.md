# Roblox OG — Edição PT-BR

Edição brasileira mantida por **Guilherme Gv** (@guilhermedigv).

O projeto personaliza a identidade de uma extensão comunitária de aprimoramento do site Roblox e adiciona uma camada de tradução para português do Brasil. **Não é um produto oficial da Roblox Corporation** e não possui afiliação, patrocínio ou endosso da empresa.

## Downloads

- [Kit de compilação e publicação (ZIP)](Roblox-OG-4.5.1-Kit-Publicacao.zip)
- [Ícone 128 × 128](Roblox-OG-GV-Icon-128.png)

> **Importante:** o ZIP disponibilizado neste repositório é o kit de compilação, não a extensão final instalável. O pacote instalável para Chrome e Edge é gerado localmente depois de executar `build.bat` no Windows com Node.js 26.8.2 ou superior. O arquivo gerado será `Roblox-OG-4.5.1-Chrome-Edge.zip`.

## Compilação

1. Baixe e extraia o kit ZIP.
2. Instale Node.js 26.8.2 ou superior.
3. Execute `build.bat`.
4. Aguarde a compilação e os testes automatizados.
5. O ZIP instalável será salvo na mesma pasta do kit, se a compilação terminar sem erros.

Consulte os arquivos `LEIA-ME.txt`, `CREDITOS-ROBLOX-OG.txt`, `PRIVACIDADE-ROBLOX-OG.txt` e `APRESENTACAO-LOJAS-PTBR.md` dentro do kit.

## Status

A compilação final ainda precisa ser executada e validada em Windows/Node 26.8.2. Nenhuma publicação na Chrome Web Store ou Microsoft Edge Add-ons é afirmada por este repositório.
